Interactive — single player Mahjong and trainers

  • Mahjong Quiz from chuuren.fr
  • Mahjong Efficiency Trainer
  • Tri Nitro Tiles Exercises — nanikiru (what would you discard) puzzles plus chinitsu wait and efficiency trainers
  • Gamedesign Flash Mahjong — very good single player Mahjong client in browser
  • Gamedesign Minimahjong — single player client with simplified rules
  • Gamedesign Bamboo — chinitsu exercise
  • Riichi Scoring Trainer — hand scoring trainer running in web browser
  • Mahjong Trainer — offline browser scoring and chinitsu trainer, can be added as a PWA
  • R Mahjong
  • Saikyo no Mahjong 3D — single player Windows client with lots of customization options
  • ChomboGen — our own hand image generator
  • Mahjong Tools — a tool for calculating winning tiles and total scores of a given hand
  • Riichi Tools — a set of tools for analyzing hands and point situations
  • Mahjong Tracker — mobile app that replaces point sticks with an easy to use interface

Mahjong online

  • Mahjong Soul — popular riichi mahjong client with anime-like visuals
  • Riichi City — riichi mahjong client with anime-like visuals
  • Tenhou — classic minimalistic client
    • Chrome Web Store: Tenhou English UI — Chrome extension that translates Tenhou UI to English
    • Firefox Add-ons: Tenhou UI translator — analogous extension for Firefox
  • Mahjong Time — advanced client with support for alternative Mahjong versions (Chinese and American, among others)
  • SEGA MJ — a client with the UI in Japanese that features advanced visuals and a voice commentary
  • Kemono Mahjong
