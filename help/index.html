Interaktywne — mahjong single player i trainery

  • Quiz mahjongowy z chuuren.fr
  • Mahjong Efficiency Trainer
  • Tri Nitro Tiles Exercises — zadania typu nanikiru (what would you discard) oraz trainery czekań i efektywności w chinitsu
  • Gamedesign Flash Mahjong — bardzo dobry przeglądarkowy klient mahjonga dla jednego gracza
  • Gamedesign Minimahjong — klient dla jednego gracza z uproszczonymi zasadami
  • Gamedesign Bamboo — ćwiczenie chinitsu
  • Riichi Scoring Trainer — trainer pomagający przyswoić zasady punktowania rąk działający w przeglądarce internetowej
  • Mahjong Trainer — przeglądarkowy trainer punktacji i chinitsu, można dodać jako PWA
  • R Mahjong
  • Saikyo no Mahjong 3D — klient dla jednego gracza dla systemu Windows z dużą liczbą opcji konfiguracyjnych
  • ChomboGen — nasz własny generator obrazków rąk
  • Mahjong Tools — narzędzie wyświetlające wygrywające kamienie dla danej ręki oraz obliczające punkty dla każdego przypadku
  • Riichi Tools — zbiór narzędzi do analizy rąk i sytuacji punktowych
  • Mahjong Tracker — aplikacja mobilna która pozwala zastąpić patyczki z punktami łatwym w użyciu interfejsem

Mahjong online

  • Mahjong Soul — popularny klient riichi mahjonga w oprawie graficznej w stylu anime
  • Riichi City — klient riichi mahjonga w oprawie graficznej w stylu anime
  • Tenhou — klasyczny minimalistyczny klient
    • Chrome Web Store: Tenhou English UI — rozszerzenie do przeglądarki Chrome, które tłumaczy interfejs Tenhou na język angielski
    • Firefox Add-ons: Tenhou UI translator — analogiczne rozszerzenie dla przeglądarki Firefox
  • Mahjong Time — zaawansowany klient z obsługą innych odmian Mahjonga (m.in. chińskiej i amerykańskiej)
  • SEGA MJ — klient z interfejsem po japońsku z zaawansowaną grafiką i komentarzem głosowym
  • Kemono Mahjong
